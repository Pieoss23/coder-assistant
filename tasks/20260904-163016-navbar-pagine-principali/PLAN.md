# Piano: Aggiunta navbar nelle pagine principali

## Obiettivo

Aggiungere una navbar condivisa alle pagine Home, About e Contact.

## Attività

- [x] Creare un componente/template navbar condiviso
- [x] Inserire link a Home, About e Contact
- [x] Evidenziare la pagina attiva
- [x] Aggiungere test per i link principali
- [x] Verificare il layout responsive

## File coinvolti

- templates/
- static/
- tests/

## Criteri di accettazione

- La navbar è presente in tutte le pagine
- I link funzionano
- La pagina corrente è riconoscibile
- Non ci sono duplicazioni HTML
- Tutti i test passano

## Rischi

Non modificare la logica di autenticazione o il database.
